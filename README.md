# 🚀 FirstGitRepo

Welcome to my very first repository on GitHub! 💻✨

## 📌 About The Project
This repository is dedicated to learning and practicing the fundamentals of **Git** version control and understanding how to connect, manage, and sync local projects with **GitHub**.

## 🛠️ Tech Stack & Tools
* **Git**: For local version control and tracking changes.
* **GitHub Desktop & Visual Studio**: For repository management and publishing.
* **PowerShell / Terminal**: For executing Git commands.

## 📚 What I Have Learned & Applied:
- [x] Initializing a local repository and saving changes using `Git Commit`.
- [x] Setting up a `.gitignore` file to automatically ignore temporary IDE files (like the `.vs` folder).
- [x] Troubleshooting file permission errors and network connection issues.
- [x] Successfully publishing and pushing the code online using `Git Push`.
